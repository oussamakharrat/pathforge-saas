================================================================================
  PathForge v3 — Textual Class Diagram
  8 Aggregate Roots · 13 Child Entities · 10 Consistency Boundaries
================================================================================

Legend:
  [AR]  = Aggregate Root        owns children, enforces invariants
  [CE]  = Child Entity          owned by parent aggregate
  [VO]  = Value Object          immutable, stored as JSONB
  [REF] = Reference Data        platform-seeded, shared
  ───▶  = Composition (solid)   within aggregate boundary
  ╌╌╌▶  = Association (dashed) cross-aggregate by ID
  ~~~▶  = Many-to-Many          via junction table
